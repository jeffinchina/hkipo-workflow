# 暗盘收盘与正式配发资料契约

- 交易资料类型继续区分 `allotment`、`offer`、`exception`；面向作者的后续主题为 `grey_analysis`，同股票同交易日18:40合并一封，辉立和富途分开列示。
- `grey-service` 是独立常驻入口，行情采集在最多两个后台任务中进行；固定截止线程不运行网络、PDF或模型审核。不等待配发公告，缺失时明确提示。
- 日历以券商明确交易安排为候选、以实际平台的当日证券/日期/时段作核验。不得把配发日、上市前自然日直接作为暗盘日。半日市收盘后取数，邮件仍18:40。
- 富途源：致富证券官方页面明确的富途报价与完整分钟响应，HK墙钟被编码为UTC毫秒须按来源含义转换；参考锚不是实际开盘。辉立源：辉立官方公开PMP日行情与明确转引辉立数据的AAStocks五分钟线，正常网页临时参数仅在内存，取完断开；不用登录交易账户。
- 开收高低取同平台日行情；真实开盘和首分时参考锚分开。富途全分钟与日高低/末价交叉核验；辉立全27个五分钟桶与独立日行情核对，采样极值不冒充真实日高低。价格、基准和每手股数缺口不得补造。
- 收盘后有界补取。成功快照、源应用响应和分时原文按SHA本地留档；`quote_only`保留已核实日行情，完整分时未过不得编走势。数据缺失、官方扫描过期或共同发行基准有分歧时，18:40仍发明确缺口邮件，冲突基准下百分比/盈亏暂停。
- 开盘前正面更正取代旧计划；已经交易的旧session历史不删除。已知旧日程回流不能取消新的未来安排。提醒组ID按股票及实际交易日稳定，避免双平台/多时段重复发信。
- 正式配发概要读取完整原文并沿用独立复核与确定性校验。当前/未来暗盘证券可核实启动时已存在的baseline招股原文，只建立IPO episode，不晋升baseline、不重发历史文章。后续分类指纹包含已核实前置episode。
- 配发资料按已验证同一期IPO episode关联，上市延期不改写已交易日；来源/当前请求/研究状态/quality/manifest/审批版本改变，缓存失效并重审。CAS防止旧后台结果覆盖新审核结果。
- SMTP前事务预留unknown，确认回执可修复崩溃边界，不对不确定结果盲重发。作者回复进入既有手机正文到公众号私有草稿流程，不自动公开发表。
