# 新股申购文章写作规范

版本 3.0，2026 年 11 月 23 日。适用于单股新股申购分析；事实核验和面向读者的表达分别验收。文字取舍以本规范为准；字体、配色、段落与封面作者默认值以作者修改后微亿智造的已保存版本为准，已登记在统一样式配置。旧样本中的数据错误、过多小数、旧引流和个人交易不继承。

## 核心要求

严谨体现在底稿和独立交叉核验，正文体现简洁、易读、友好。底稿须完整核查来源、单位、币种、期间、条件、计算和互相矛盾的披露；读者不需要看到整个核查过程。

正文没有复述标准合同条件、一般风险、例外流程、核验步骤或每个计算参数，不构成事实遗漏。只有会实质改变业务理解、盈利质量、发行货量、实际成本、参与条件或投资判断的信息，才需要用最短的准确表述保留。不得用简洁掩盖错数、错口径、重大亏损或真正影响结论的例外。

标题默认「港股打新 股票简称」。一个短导读后，沿用五节：一、基本情况；二、财务情况；三、发行情况；四、估值分析；五、最后总结。内容多少由重点决定，不按招股书逐项搬运，也不凑字数。

## 基本情况要让普通读者看懂

通常一段，先说公司给谁提供什么产品或服务、解决什么实际问题，再补一个最有辨识度的行业位置或收入来源。成立时间、总部和产品清单按相关性取舍。

陌生英文缩写不直接充当业务解释。可省略的缩写直接省略；必须使用时，首次用一句普通话解释其实际用途，不能只展开成另一个读者仍看不懂的中英文术语。产品型号与业务缩写区别处理，不擅自改写名称。例如，不只写「收入来自 EIIR 产品」，而要据原文说清是什么机器人、在工厂里做什么。解释完就收住，不再另加一段百科。

排名保留必要的年度、地域和细分范围，不能把细分行业第一写成整个机器人行业第一。已核实的关键限制可压成一句，不重复多层审计限定语。

## 财务只挑重点

营收和净利润或净亏损是默认骨架，通常各用一个小标题、每年一短行，保留两至三个可比完整年度。必要时补最新一期及同比。组标题或首行说明币种，后续同组不反复写币种和会计口径。

先用未调整利润，避免用调整后盈利掩盖实际亏损。经调整利润、备考数据、经营现金流、毛利率、应收账款、现金储备等，只挑会改变判断的一至两个重点。某项对理解盈利有实质影响时用一句交代，不另写成长篇会计说明。不要机械凑齐所有财务指标。

例如，信贷亏损拨回、收购备考或调整后利润须在底稿核查；正文是否写出，应看本篇是否需要它来支撑或纠正实际结论。只简短列示净利润、没有作稳定盈利或主营造血很强的断言时，不机械要求把拨回分类和全部备考说明补进正文。若正文判断依赖盈利质量且会被遗漏信息误导，则补一句最必要的说明。作者这次选择营收、利润及应收回款作为财务重点，应学习这种取舍，不把每一项核验所得都强塞进正文。

无收入企业直接说明尚未商业化，不列连续三年零收入。负数改善不等于转正；净利润、归母利润、经调整利润及备考利润不可混用。

## 数字显示最多两位小数

正文中的金额、百分比和倍数最多保留两位小数，通常一位或两位即可，能够用整数说清楚就用整数。不要为了与原始报表逐位一致，写成「7.95504 亿元」「4.34026 亿元」。对应显示为「7.96 亿元」「4.34 亿元」。同组金额的精度尽量一致，不强制补无意义的零。

金额优先用亿、万等易读单位；百分比通常一至两位，估值倍数通常整数或一位。股价、含费用入场费等实际金额可保留两位；日期、股票代码、产品型号、整数手数不按小数规则改写。金额很小时应换单位，不把有意义的非零数舍成零。四舍五入不能改变正负号、盈亏方向、区间边界的含义或将接近百分之百写成确定全覆盖。

底稿的原文数字、精确值、计算与舍入记录照常保留，可以超过两位小数。核验时按正文所用单位和显示位数检查正确舍入，不以正文没有全部原始小数判错；不用为了显示舍入而把原始事实值改粗。

## 发行情况一项一行

沿用十个标签及顺序：申购时间、发行价格、每手股数、入场费、发行数量、市值、绿鞋、发行方案、保荐人、基石。标签用全角冒号，具体字体和颜色跟随作者样稿。

申购时间写简短起止日，例如「11.23—12.1」，需要时简注预计上市日。完整年份、时区、各渠道付款截止等留底稿；确有特殊安排会改变操作时才简短补充。提醒系统读取完整 ISO 日期，不能拿正文短日期猜年份或混用券商提前截单日。

发行数量优先写香港初始手数，避免把全球量或条件回拨上限冒充初始香港货量。按需要用整数手数或一至两位小数的万手。市值说明必要的价格基准即可，不搬出全部股本和换算过程。

绿鞋正文默认仅写「有」或「无」。授权与否在底稿核实，不把是否最终行使、借股同意、稳价安排、终止条件等通用或附带条件全写出来。只有会实质改变「有／无」结论或投资判断的特殊安排才补一句。不因正文没有这些条款判作疏漏，也不从上市章节或是否有稳价人猜有无绿鞋。

发行方案简写机制及有用的货量判断。通常不穷举触发组合、酌情调配、承销兜底等标准条件。若正文主动写最大手数，就须保留足以说明它是条件上限的简短限定；不需要为了完整展示底稿而主动加入最大数。

保荐人标题只写「保荐人」，名单用无歧义常用名，完整法律名称及角色关系留底稿，不混入承销商或账簿管理人。

基石正文以「无」或「有，机构名单，合计认购约 X%」为基本形式。有基石时列相关机构，家数较多可列主要机构加「等 N 家」并给合计比例，完整名单留底稿；比例分母须正确，首次公开发售前投资者不可冒充基石。仅真正特殊且影响判断的情况补一句。

不能为了符合「有／无」格式，将尚未核实、仅未检索到或未披露直接写成「无」。事实状态在后台补源、交叉核验并收敛；真实无法确认时保留后台缺口，不把核验过程和异常链路写进读者正文充数，更不能虚构结论。

## 估值与总结保持短

估值通常一短段，给适用的 PE、PS、A/H 折价或相应判断。必要的年份和利润口径要说清，完整分子、分母、汇率、股本、区间计算留底稿。没有可靠来源不编可比公司、行业倍数或市场热度；无收入、无利润时不硬算假倍数。

总结通常三至四个短段或短条，集中说赛道、基本面、发行结构和当批冲突等真正的取舍，不把前面的所有数字再抄一遍。语气自然直白，允许「货量」「肉」「二婚股」等已有声线，不套泛泛的研究报告结语，不保证收益，不编作者仓位、交易或参与计划。

## 排版和草稿默认设置

字体、字号、正文颜色、章节标题颜色、段落间距、对齐和引流文字的独立颜色，均以作者修改后微亿智造的实际保存版本为准。把提取值保存为有来源记录的统一样式配置，HTML、邮件和 Word 使用同一配置；不能只改规范文档而保留渲染器旧的固定颜色。

文末依次为既定引流、独立风险提示段落、原始个人微信二维码。引流和正文允许不同颜色，风险提示单独处理；二维码保持原图及纵横比，使用既有居中展示规则。作者本次没有新个人内容时，不加心情、仓位或闲谈。

已提取的当前配置如下：

以后新草稿默认使用作者在该样稿选定的封面和作者署名；留言默认开启，默认不额外限制仅粉丝可留言。封面、作者和留言开关必须实际进入草稿 API 字段，并参与投递去重指纹，不能只写在说明文档里。正文已有作者修改的现存文章不因更新默认配置被自动重写或重新发表。

同日拟群发两篇或以上时，组内各篇使用不同封面。按[配置与运行](operations.md)逐篇检查原创选项并准备整组预览。

## 独立双重验收

事实复核先从完整正式原文独立核查身份、时间、财务口径、名单、发行机制、单位换算及计算，逐项处理矛盾与缺口；机械检查精确值与舍入过程。正文中每个实际使用的实质事实要有关联证据，保留内部精度。

成稿复核另外看是否说人话、财务是否挑重点、小数是否过多、缩写是否解释、标准条款是否堆砌、颜色段落是否符合样稿。底稿完整不等于正文必须逐项展现；正文正确的精简、正确的舍入及未展示默认条件不得被当成事实不完整。

需要修改时只针对未通过项，保留已经核实和无关的部分，复核新稿是否引入新错误。全部内容关通过后再渲染，检查 Word 每页及必要的手机呈现，冻结同一版后交邮件和私有草稿。真实未解决的问题留后台可见状态，不能靠降低事实标准或无限补充正文来过关；不自动公开发表。
