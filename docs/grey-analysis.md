# 暗盘点评分析规范 v1.0

适用于暗盘收盘后的资料邮件和作者后续点评。参考本次保存的六篇暗盘分析样稿：短段、突出当日变化与中签难度，不套申购分析五段模板。旧文中的个人持仓、卖出、资金分配和收益，均不能变成本次作者的个人事实。

## 数据与提醒

- 每只股票在实际暗盘交易日的香港时间 18:40 发送一封邮件，辉立与富途分别列示。半日市也保持 18:40。正式配发公告不能作为排程的唯一触发器。
- 日期依据券商明确暗盘安排，辅以已核实上市安排及实际平台的当日证券、交易时段和行情时间；不能把配发PDF日期、网站发布时间或上市前一个自然日直接当成暗盘日期。
- 收盘后一次性取得完整当日分时和日行情，失败时只作有界补取；不实时盯盘。过往实际交易的 session 留档，开盘前明确更正的旧计划应被新安排替代。
- 正式配发公告没出，在邮件明确写“正式配发公告尚未公布”；已出但资料未核验则写“已发布，概要数据尚在核验”。不因此延迟18:40邮件。晚到公告继续提取、复核并保存，不重复发送当日提醒。

## 必需价格事实

每个平台独立保留：发行价、每手股数、真实开盘价、收盘价、盘中最高价、最低价、四个价格相对发行价的涨跌幅、一手最高浮盈及最大浮亏。两个平台的高低点、收盘和分时不得拼接成一条行情。

盈亏统一以按发行价中签一手为基准，价格差乘每手股数，未扣费用；只表示账面浮盈浮亏，不等于作者实际成交。全程未低于发行价时最大浮亏为零；全程低于发行价时最高浮盈为零，仍保留各价格的真实负收益。显示最多两位小数，内部保留精确值及舍入依据。

不增加成交额、振幅、高点至收盘回落幅度这三项。源响应可以原样留档，其中的附带字段不自动变为文章或邮件字段。

## 简短走势点评

根据完整分时写一至两句，优先说明高开或低开、冲高或回落、开盘与收盘的关系。只有真实分时支持时才描述“先冲高后回落”等先后顺序，不从四个日价格点编造路径，不把每分钟的全部数字搬入正文。

分时图首个参考价可能是发行价或昨收参考值，不能直接作为真实开盘价。开盘取同平台有明确定义的日行情字段；图表参考锚原样留档并分开解释。日高低、末价与完整分时交叉校验，矛盾项继续查，不为通过审核改数。

语气可以自然直接，但不虚构行情原因、市场情绪、资金动机、个人中签或实际卖出。旧文“我中的还没出”“验证了我的判断”等句式，只有作者当次明确输入才能使用。不因某天暗盘涨跌推导次日必涨必跌。

## 正式配发概要

保留完整官方公告和独立复核后的底稿，包括最终定价、公开与国际认购、最终两池分配、回拨、分配表和集中度等。资料邮件挑重点列示，完整表及证据留本地；“暂未公布”和“没有该项”不能混为一谈。

发行期通过已验证IPO episode关联，延期后最新上市日与已发生暗盘日分别保留；不同发行期同代码不能串联。复核、证据与精度要求不因邮件简短而降低。

## 来源与版式

富途行情可使用券商官方转引且明确标注富途的平台资料；辉立日行情取辉立官方，完整分时允许使用 AAStocks 官方行情中明确标注“资料来源：辉立证券”的同平台资料，并交叉核验。邮件实际列出各自来源；不把AAStocks说成辉立自建网站。

只拿到日行情时保留已核实数据，并明确完整分时缺失，不编盘中路线；缺少可信发行价、每手股数或最终收盘状态时，相关收益与结论暂停，缺口在固定时间邮件中可见。

作者回复后仍只生成公众号私有草稿，沿用已验收的统一字号、配色、段距、作者、封面与留言配置，不自动公开发表。内部核验步骤不写入读者正文。
