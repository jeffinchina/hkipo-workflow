# 延期短评与其他异常公告

## 延期上市：先报事实，再说几句

用户于2026-11-20明确：过去没有专门的延期上市文章模板。不要把历史综合短札或此前《同仁堂医养 先等退款》验收样稿当成已认可模板。参考研究见项目 `research/postponement-references/comparison.md`；三篇外部文章只提供写法参照，不提供新一期的事实或用户观点。

默认写一则及时、简短的事件短评。开头一句交代哪家公司、全球发售或上市发生什么变动；有必要时说明原定日期已经不能沿用，新日期只按公告披露写。然后用两至四句有根据的市场点评回应打新人关心的事情，自然结束。有确实相关的同日分配或申购信息，可顺势接一小段；没有就不拼凑。

约150—350字仅作为独立短稿的起步参考，不是最低字数或硬上限，必要时更短。短句、短段、判断直接；不强制小标题、旧新对照表、五段模板或结尾总结。结合作者近期的口语和克制判断，不照搬别人的尖锐措辞，也不强行制造笑话、愤怒或仓位。

核心是尽早告诉读者延期事实，不写成退款说明书。退款只在有实质提醒价值时带一句；涉及必须撤单、重新申请、明确时限等会影响读者操作的事项，应简短明确提醒。接收银行、券商到账层级、佣金征费和利息等细节保留在内部事实账本，默认不进正文。不能因没有这些可选细节而卡住一则已证实的延期消息。

不要因为事实账本已经提取了某条就把它塞进短讯。承销协议是否签订或成为无条件、不交付股票等法律细节默认不展开；只有它直接改变读者需要做的事情时才用白话提醒。没有同期市场背景时，事实短讯可以只有两三小段、更短于150字，不以承销条款或券商退款核实流程填充篇幅。

市场点评须有当时、同一语境的依据。不得把第三方旧文中的热度、国配不足、折价或改革评价移作本期事实。官方没有解释原因时，可以有明确标识的简短推测，但不能写成“因国配不足而延期”等确定因果。延期不等于永久取消，也不能自动称为已经证实的发行失败。没有可验证的同期市场背景时，先产出事实短讯，不补“市场很冷”等背景句，也不为等待可选点评拖住消息。

## 阅读和验收边界

正文可以很短，当前官方延期公告仍须完整读取并核对公司、代码、事件性质及影响。新安排、官方原因、投资者行动等在内部逐项记状态；未披露不等于没有。当前公告足以证明的延期事实，不要求先读完它提到的全部旧招股书。只有正文比较旧定价、旧条款或推断变更影响，而当前文件不足以支持时，才补对应前件；不能把前件缺失一概升级成整篇短讯不可写。

独立核验仍核事实、证据、标题和没有数字的断言。可选退款细节、未用的前件、点评篇幅及个人风格属于缺口或编辑建议，不是阻断项。实际行动指令必须有依据；缺少依据时省略指令，不杜撰，也不把“没有查到”当“无需操作”。会直接误导投资者的关键遗漏仍须阻断。

## 撤回、更正及其他异常

不要把延期短评机械套到所有异常。先确定当前有效文件变更了什么，区分延期、撤回、更正和重新启动。若涉及原申请是否有效、是否须重新申请、价格或数量变化等实质影响，优先简明交代影响及有依据的行动；只有确实需要才用短对照表。必要的旧新比较读取相应前件，未证实原因不代填。旧图不能当新公告证明，需截图则来自当前已读文件并标注版本页码。
