# 分配结果/暗盘前后更新

用户2026-11-20新增“出签快讯＋本人正文”优先流程，详见项目`出签快讯与本人正文入口.md`。早期券商甲乙组图先给作者和两至四句简读，主体由作者在入口填写；规范以排版、固定风险提示和引流尾部为主，不默认代写主体，不等待完整官方公告/国际配售数据才提醒。以下完整公告分析作为正式资料核对和可选深入分析规则，不能机械套到早期快讯或作者自写短文。

不用招股五段和800字套出签文。根据事件，从分配难度或当天变化进入；用户提供个人战报才可“先说我的”。明确最终定价/上市安排、公开及国际认购热度、最终两池分配、实际回拨和集中度。分配表按实际适用档位说明甲组/乙头/顶头锤及稳中、抽签概率；百分比不是保证中签，申购金额不是货值。

读完整分配表、附注及相关公告，不能只截甲尾/乙头三行；存在多类别、重复申请/无效申请或集中度附注要说明影响。对比同批新股可用相同口径，没来源不造倍数/中签率。可接下一截止或资金释放日，但券商实际释放因渠道不同，不把官方结算日当用户可用资金时点。

暗盘/首日区分发稿时点、最高价、当前价与作者实际成交。未提供成交就不写“已经走了”、未提供户数就不写“四户中两手”。短句与情绪可自然出现，不强制笑话、焦虑、晒收益或建议融资全梭。末尾用简短风险提示和关注句即可，非每篇都要二维码。
