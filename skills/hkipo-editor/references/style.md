# 共同声线和渲染参考

基于2026近期公开文章：句首先说当下矛盾、数字紧接短评，业务长解释与一行判断交替。可自然用“货量”“肉”“卷”“二婚股”，不随机撒术语。“估计/可能/大概率/先观察”保留不确定性；讲具体取舍胜过堆形容词。招股长文较有结构，出签/暗盘短文像朋友聊天。不要抄历史股票数据、观点或把原作者交易当用户当前交易。非投资戏曲文章只作声线对照，不迁移粗口为投资文章要求。

明确区分披露事实、计算、作者观点及他人预期；博主/群聊涨幅猜想不变成作者主张。既可坦率评价基本面，也可说市场情绪影响参与；不要把每篇变成“好基本面就一定上涨”。口语不等于故意错字，历史自相矛盾比例与财务错误应修正。

用户2026-11-20指定所有文章统一文末，顺序如下，保持原句，不因体裁或模型自行改写；风险提示必须另起一行（独立段落）：

看到这里，点个赞吧，新朋友点个关注，第一时间推送打新笔记。

风险提示：本文内容仅为个人分析记录，不构成任何投资建议。打新有风险，参与需谨慎。

上述文字后使用用户在本机私有目录配置的二维码原图；路径与 SHA-256 通过 HKIPO_QR_PATH 和 HKIPO_QR_SHA256 配置。保持纵横比，不裁剪、重绘或改色。二维码和封面不随仓库提供，必须使用有权使用的个人素材。无当次心情不写心情指数。

纯文本结构稿不含HTML/Markdown装饰。默认样式以2026-11-23作者保存的微亿智造富文本副本为准，统一来源为assets/branding/draft-profile.json，不用旧文覆盖新样稿。正文可见叶子16px、行高32px、rgba(0,0,0,0.9)、字重300、段后24px；章节与财务小标题#2B77BF、字重400、段后12px；发行字段标签字重400。引流仅“点个赞”“点个关注”两处用#FFA900加粗，其余同正文；风险提示独立蓝色段落。总结的短条使用有序列表，不自动生成评分。HTML保留原色及透明度，Word按白底映射等效色。父块17px/20px不是可见叶子字号。

作者署名由私有样式配置提供，默认封面为用户自行配置的封面永久素材，留言默认开且不额外限制仅粉丝；这三项须实际写入草稿字段。作者的新明确选择优先于此默认。不能自动修改已发表文章或覆盖作者改稿。

历史参考基线仍可用research/published/style-evidence.md、format-profile.json和近期单股文章；其历史数据和旧排版不覆盖本次明确偏好。
